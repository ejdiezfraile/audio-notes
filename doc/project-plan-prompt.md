Actúa como un asistente técnico que quiere generar un project-plan.md.

Tengo una descripción técnica de un proyecto que te paso como contexto (no la reescribas).

Tu tarea es crear un fichero project-plan.md con la siguiente estructura en formato Markdown:
1. Título del plan  
   Utiliza el título: # Plan de proyecto: [nombre o descripción breve del proyecto]
2. Objetivo
   Resume en 4 o 5 líneas el propósito principal del proyecto. Responde:  
   - ¿Qué problema resuelve?  
   - ¿Cuál es la solución general?  
   - ¿Qué tecnologías principales se usarán?  
3. Todo Items  
   Divide el trabajo en secciones temáticas o áreas funcionales (1, 2, 3, ...).  
   Dentro de cada sección, incluye tareas en checklist (- [ ]) 
   Añade subtareas si es necesario.  
   Ejemplos de secciones típicas:  
   - Setup inicial  
   - Backend  
   - Frontend  
   - API  
   - Base de datos  
   - Autenticación  
   - Testing  
   - Deployment  
   - Otras áreas específicas que detectes según el contexto  
4. Preguntas clave a responder 
   Lista de dudas técnicas, riesgos o decisiones clave que deberían resolverse antes o durante el desarrollo.

Muy importante:  
- No incluyas la descripción técnica original dentro del resultado.  
- No inventes funcionalidades que no estén sugeridas en el contexto.  
- Mantén el lenguaje claro, directo y orientado a desarrolladores.
Ahora te paso el contexto del proyecto:
